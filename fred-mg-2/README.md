# fred mg2

原视频抖音来源：[FredTalk《11月GitHub十二大神级项目，三家大厂齐下场》](https://www.douyin.com/video/7712675882543975689)，[分享链接](https://v.douyin.com/Uh1odKiCyaE/)。

这是独立的暖金黑底项目榜单模板，与 `fred mg 1` 分开。模板按原视频的竖版画幅、30fps和原时序登记43个可单独取用的场景，覆盖榜单归位、真实网页入口、标题揭示、星数计数、逐行终端、卡片追加、单焦点轮换、成本条收缩、纸卡展开、任务看板、聊天反馈与评论输入。复刻横版另作场景重排，不能把竖片缩成小窗。

原时序模板保持1080×1920、30fps、7872帧、43场。横版复刻是独立工程：1920×1080、30fps、10097帧，使用336.56秒自然原速旁白，只重排原片已有动作；这不把公开竖版示例改成横版，也不以字幕变化代替正文推进。

内部已用专用Python审片流程检查baseline与r1，持续运动候选由18项降到2项；r1、r2和r3均已完成专用审片及全片半秒／末帧526张OCR，程序退出0。r3保留29项候选（28项主候选、1项持续运动候选），结尾清单预览的运动密度差异仍实存。候选减少和OCR执行成功不等于缺陷已确诊、所有文字可读或审美通过，不能写成全部问题归零。原片长阅读停留如实保留在模板；已知动作修订与范围见[修订状态](docs/revision-status.md)。

## 使用

需要 Node.js。公开示例只带源码、许可字体和通用媒体插槽，没有原视频、原音、第三方案例、个人角色或凭据。

```sh
node fred-mg-2/tools/build.mjs
node --test fred-mg-2/tests/motion.test.mjs
python3 -m http.server 8000 --directory fred-mg-2/.build/source
```

在系统 Chrome 打开终端显示的本机服务地址，进入 `index.html`。渲染时使用已安装的 Hyperframes 插件入口执行检查、查看时间线并导出；本仓库不内置账号或本机安装路径。

配置入口为 [原时序示例](examples/source-timeline.json)。修改场景的 `nodes`、`bounds`、`text`、`media` 与 `tracks`；每个对象有独立标识。键轨格式为 `[帧号, 数值, 缓动]`，以绝对整数帧定位。没有键轨的属性保持固定，不自动添加漂移、弹跳或循环。

`from` 包含，`to` 不包含。`count` 用于数值或打字进度，`reveal` 用于水平揭示，`x/y/scale/rotate/skew` 控制本对象及子层，`height/width` 用于已有扩展结构。网页案例通过独立媒体槽替换。内部实际Hypit工程按逐帧源time map绑定连续案例，播放速率为1倍；不是抽55张截图再长期保持。公开包只有通用插槽，不能拿占位图冒充真实录屏，也不分发该私有映射对应的案例媒体。

## 动作与边界

- SEO审计按行累积，前面已完成项保留；Obsidian四窗按单个焦点轮换，前一项回弱。
- XERJ绿色成本条从长收短，不由零增长。上下文压缩条先整组建立，再于本片原时序4498—4522帧从694收至139，左锚固定；不能误写成一直满宽，也不能缩扁文字。
- 纸卡按段落整步增高：高度311、581、792；4627和4660帧追加后两段。旧段与底标保留，不把跳变改成长时间高度补间。
- Handy使用18条波形，3715帧起为弱态，3825帧进入发声态；结果整组显现，不能擅自改成打字。人物和原片个人身份在实际媒体中分别处理；五处头像改用项目文字标识，不冒称官方Logo。
- 打字、计数和卡片追加不是同一种淡入。任务看板保留真实案例自带的透视，不再叠加skew制造假3D；保留源画面透视也不等于恢复了原工程的三维参数。
- 结尾的品牌、岗位示例、性能及星数均须按实际内容替换；不会自动继承作者的制作声明或资源承诺。

当前重做的宽斜英文标题采用Orbitron 900作字形近似，正文采用NotoBold；原片字体身份没有认证。公开目录已附[Orbitron字体](assets/fonts/Orbitron-variable.ttf)及[OFL许可](assets/fonts/Orbitron-OFL.txt)，不把字体选型当成字形完全一致。
