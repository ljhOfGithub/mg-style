# 组件接口

[绘制](src/components.mjs)、[状态](src/motion.mjs)和[运行时](src/runtime.mjs)分开。11族包括页头强调、整卡入场、错峰卡组、流程带、媒体插槽、机器人闭环、多任务现场、五人组、单字幕窗、贴纸、独立流水线。具体方法见[目录](components/catalog.json)，族数不等于特效数量。

## 参数和单位

componentHtml(c)按显式renderer分派：card、case-frame、robot-loop、task-world、people、sticker、outro-line。id只绑定对象，建议使用自己的名字。kind决定运动：card普通卡、phone固定比例媒体框、world整组主视觉、sticker贴纸。cardStyle支持module、audience、compact或空字符串；compact减内边距与行距，不缩字号。rect为2880×2160设计坐标中的[x1,y1,x2,y2]，绘制时除2，不是[x,y,width,height]。

text使用[tag,title,copy]；贴纸使用[大字,小字]。color与shadow控制卡片和投影。robot-loop可用brand、diagramLabels四标签及diagramColors（create、publish、engage、monetize、core）。outro-line可用brand、actorSrc、diagramColors（paper、create、publish、growth、engage）。actorSrc省略或null均不放图片；传真实路径时由使用者准备资源。接口不附私人角色。

## 帧状态

anchors的first、middle、clear是全局绝对帧；absent标前态。settleState(frame,c)纯计算opacity、x、y、scale、blur；applyState(element,state)应用到节点。普通卡默认透明度0.025→0.66→1，尺度0.955→0.982→1，软边2→0.8→0。phone/world保持scale=1，横移18→0、竖移9→0；普通卡竖移15→0。贴纸回位可能持续到clear+8，clear只保证透明度完成。

headerState(frame,scene)自章起点+4开始，12帧建立；highlightState(frame,{highlight:[start,end]})独立计算重点底色进度。错峰由每张卡自己的anchors表达，不能用总淡入代替。原片精确曲线并未恢复，这些是本库明示参数。

## 整片配置与运行时

config包含width、height、fps、frames、duration、palette、scenes、captions和media。当前validateConfig要求30fps；scene.frames为连续半开区间[start,end)，首尾覆盖frames。每章包含header、headerEvent.highlight和components。

filmHtml(config)生成场景和唯一caption窗，外层root还应有.paper节点。createFrameRenderer(config,root)返回renderFrame(absoluteFrame)与renderAt(seconds)，后者按Math.round(seconds*fps)定位。正反寻址不累积上一帧状态。runtime只控制画面，不自行播放、暂停或seek媒体。

scene.captionTop是输出像素y坐标。省略则沿用CSS默认845；换章或反向跳帧会按当前章设置/恢复。长字幕应检查与真实UI、投影和页尾的间隔，不把某个数值当通用答案。

captions每项为{start,end,text}，时间单位秒；只更新一个字幕窗。图卡文字与口播字幕分开。

## 媒体槽与导出

media以key登记file、first/end、display、crop与redactions；first/end为帧，display为输出像素[x,y,width,height]，crop与redactions为设计坐标[x1,y1,x2,y2]。file相对assets。媒体由实际引擎按原速推进；替换自己的媒体时同步时窗、几何与遮罩，不能保留不适用的旧redactions。mediaKey优先显式选择槽；无媒体时只显示空框。

```bash
node tools/export-component.mjs --id note-card --config examples/card.json --out .build/my-card
```

导出把first移到第15帧，默认4秒，保留已有位置而非自动居中。复制examples中的JSON即可换内容。Hyperframes渲染依赖已安装插件；Hypit桥接需自己的Producer、Window、媒体和Run工程，本包没有远端凭据。
