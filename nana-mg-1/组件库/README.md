# nana mg1 独立动效组件

15个组件各有独立源码与配置，单独构建为可移动的Hyperframes工程。无需读取旧视频的30段时间线、章节预设或复现素材。

[打开组件预览目录](预览.html) · [查看15个预设](目录.json) · [查看5个片段配置](样例配置/) · [查看制作计划](制作计划.json)

播放器展示已经渲染好的样例。修改配置后，要重新构建和渲染，播放器不会冒充实时生成结果。

## 构建一个组件

以下命令从仓库根目录运行，Python 3.11以上，只需要标准库。

```sh
python3 nana-mg-1/组件库/构建.py --component 06-fan --output .build/my-fan
npx hyperframes@0.9.97 preview .build/my-fan
npx hyperframes@0.9.97 check .build/my-fan --json
npx hyperframes@0.9.97 render .build/my-fan --fps 30 --quality looks -o my-fan.mp4
```

`my-fan`包含自己的HTML、动画、配置、图片、字体和运行库，复制整个目录即可继续编辑；图片是独立文件副本，修改它不会改动其他导出或源素材。各组件共享的是源码绘制原语，不共享可写的媒体文件。

## 更换文案、图片与时长

从`预设/`复制对应JSON，再修改`content`、`media`、`duration`。图片路径相对于`--media-root`，不是相对于配置文件；不指定时使用本组件库的`素材/`。

```sh
python3 nana-mg-1/组件库/构建.py --config my-config.json --media-root my-images --duration 6 --output .build/my-new-clip
```

最小配置如下，省略字段会采用该组件自己的预设：

```json
{"format":"nana-component@1","component":"06-fan","duration":6}
```

- `content`只接受该组件实际使用的字段，清单见[目录](目录.json)。纯媒体组件02、04、10没有文字字段，不假装支持改标题。
- `media`接受PNG、JPG、WebP、SVG；13的背景另支持原速MP4/WebM，视频不能短于组件（检查需本机ffprobe）。默认完整容纳图片并保持比例。`options.slot_options`可明确选择`contain`或`cover`、位置、圆角和边框。`cover`表示允许裁切。
- `theme`支持强调色`accent`和导航高亮色`nav_accent`，使用六位十六进制值。
- `duration`多数支持3至12秒；05编号卡、06五卡和07共同溶出支持1至12秒，07双层翻页仍至少3秒；13双次描勾支持2.2至12秒。按30fps的帧边界对齐；增加时长主要增加中间展示时间，入场动作不随总长一起放慢。
- `options.motions`按`动作参数.json`中的“对象:次数”覆盖`start`和`duration`。不存在的动作、零时长或越界时窗会报错。
- 07通过`options.exit_mode`选择`peel`双层翻页或`dissolve`共同溶出，后者保留完整资料页；剥离与共同退场跟随当前时长，保留镜像背面；13描勾保留两次描线及中间清空。不同组件不共用一套淡入。

正文不自动省略或截字。标题通常最多24字；07为22字、11为25字、12为16字。副标题35字、正文48字、徽标10字；网格说明每项24字、五卡说明56字。条目数按版式固定，节点标题最多8字、导航每项10字。超出边界会提示修改，不能把有限验证当成任意长文保证。

当前支持1920×1080、30fps、16:9。未验证自动竖屏重排、任意卡片数量、超长正文或任意视频输入，不声称支持。

## 组件与来源

各组件从`nana mg1`提交`39eba1b45f8f197e890682612b8e10c230368bf6`的动作函数拆分，具体原片时窗、函数名和字段保存在[目录](目录.json)。底座、斜切与独立时窗沿用原库已有的来源与许可，不重新设计成另一套动画。

| 组件 | 可替换内容 | 固定动作结构 |
|---|---|---|
| 01 居中标题 | 标题、副标题、底图 | 大字短促收回、文字分组显露 |
| 02 媒体窗 | 底图、前景图片 | 抬入、斜切旋转退出 |
| 03 六宫格 | 标题、六项名称与说明 | 六卡整组显露 |
| 04 叠窗 | 文档、预览、底图 | 两窗分时抬入、整组斜切退出 |
| 05 章节卡 | 编号、标题、用途、配图 | 底面、配图、数字、说明分层显露 |
| 06 五卡展开 | 五项名称、说明、图标 | 中心堆叠变为上二下三 |
| 07 双层翻页 | 摘要、前后两图、底图 | 镜像剥离、底层露出、共同退场 |
| 08 节点窗 | 四项能力、三项节点、标题 | 应用窗与节点分组显露 |
| 09 媒体分区 | 多张图片、列表、标题 | 基础分区、追加三图 |
| 10 悬浮媒体 | 三图、底图 | 三块媒体暂留并退去 |
| 11 故事板 | 三图、标签、标题 | 浅底、标题、框和三组内容显露 |
| 12 大字强调 | 短标题、底图 | 超大字收回、清晰停留、右移退出 |
| 13 双次描勾 | 徽标文字、标题、底图 | 标签、描勾、清空、再描勾 |
| 14 生产链 | 五步名称、标题 | 五卡从左至右短错峰显露 |
| 15 导航 | 六个章节名称、标题 | 固定导航随章节切换高亮 |

图片为本库通用示意，不是实际软件界面或个人实测。原片与左右对比只保存在本地验收目录，未随公开组件库分发。参见[风格来源与许可](../来源与许可.md)。

## 原片素材展示与替换验证分开

按用户要求，5个最终展示片段使用原片对应素材、文案和原时长，并另交左原片右组件的本地视频。参考素材与对比不上传公开库。本目录的通用预览只用于检验参数替换，不冒充原素材复现。

05支持`eyebrow`、`usage_label`、`input_label`和`output_label`；06的`layout: reference`使用较大图标，11的同名布局恢复原分镜插槽位置。13的`layout: overlay`只接受`badge_text`并保留输入底图的标题；`motions["badge-reset:0"]`只设置瞬时清空的`start`。
