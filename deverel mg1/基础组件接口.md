# 基础组件接口

全部SVG组件接受`(props, frame, theme, curves)`；`frame`为30fps的整数或可求值时间，`theme`包含背景、墨色和强调色。未用到的参数可省略。函数不依赖上一帧，不使用系统时间或随机数。对外文本先转义，支持换内容。

`renderScene(config, seconds, curves)`负责整片编排；`sceneAt`选中对应段落。组件自身不决定事实或声画认可。

| 组件 | 主要配置 | 真实动作与用途 |
|---|---|---|
| overviewList | list、overviewNumber、overviewTitle | 数字与七行总览；末两行短建立 |
| priceCard | text、x/y、at | 整卡小角度回正，非整场景缩放 |
| modelTimeline | models、modelsHeading | 单向线条延伸，模型节点错峰下落/向桶收拢 |
| backdropWord | text、size、at、alpha | 大背景词成为弱层，不抢主体 |
| bundleBucket | word、at、x/y | 桶从下方上冲，再回稳 |
| twoStageNotes | title、note、titleAt、noteAt | 两层说明独立接续 |
| quotaGrid | target、label、rows、columns | 一个离散计数源同时驱动数字与亮格 |
| gpuCard | title、value、note、at | GPU整卡短上移并建立 |
| formulaCard | text、at | 公式整卡短建立 |
| verificationRows | rows、ats | 每个核对行作为完整对象短建立，无额外上下漂移 |
| contrastGroup | lines、at、curve | 按实际测量明度建立完整文字组 |
| terminalPanel | lines、at、title | 所有终端行作为一张板建立，不伪造执行打字 |
| stepList | items、notes、ats、showAllAt | 当前整卡原子切换，前一项同刻失活 |
| metricPair | items、at | 两张数值卡分别建立并增长 |
| inputChain | items、at | 输入、编辑、结果的分组关系；箭头不循环 |
| ring | label、at、duration、r | 单次环形进度建立；无无限旋转 |
| modelList | notes、ats、activeBlocks | 模型项高亮与对应解释接力 |
| fourMetrics | items、at | 四格各自数字增长 |
| waveform | at、bars、label | 下方波形槽的局部柱线变化 |
| taskPanel | rows、rowFrames、at | 父板先建立，再一次追加整行，不逐字打字 |
| receiptCard | lines、total、stamp、at | 账单整体接入，印章作为静态附着物 |
| storagePanel | title、value、family、at | 存储环、家庭轮廓与容量关系 |
| closingCard | title、subtitle、symbol、at | 四帧成组建立；不用对方头像和署名 |
| mediaWindow | src、x/y/w/h、start、duration | 接入真实案例，保留连续动态；不是原片整幅包装 |
