# deverel mg1 组件接口

38个绘图入口分为23个基础兼容组件和15个分层组件；媒体适配器和状态函数另列。组件返回当前帧的SVG或状态，由Hyperframes时间线调用。三个示例的文字、数字和时序均可独立修改。

## 时间、坐标与配置

示例JSON 管内容、时窗和媒体；[整片编排](src/refined-scenes.mjs) 绑定各段组件；[通用组件](src/refined-components.mjs) 与 [呼吸环组件](src/gap-ring.mjs) 实际绘图。下一条视频可以直接使用独立组件配置，不需要继承 Google 的整片或时码。

| 字段 | 单位和用途 |
|---|---|
| width / height | 最终输出像素。本构建器使用1280×720逻辑画布，按 width/1280 等比缩放；改变宽高比需要重新排版，不能只改height |
| fps / sourceFps | 当前均为30。fps是输出帧率，sourceFps把秒换为组件帧；全片当前按30fps实现，改帧率须连字幕和源曲线一起适配，不承诺只改一个字段自动兼容 |
| duration | 整条工程的秒数；与组件props中的duration不同，后者通常是入场所用帧数 |
| timings.scenes | `[场景名,开始帧,结束帧)`；结束帧不包含在该段，整片各段应连续 |
| component.type | 独立绘图组件名称，如 independentMetrics、pulsingRing |
| component.props | 该组件的文字、目标数字、坐标、入场和变化曲线 |
| component.background | 独立组件示例的画面底色 |
| background | 组件theme：dark、light、ink、muted、blue、gold、green |
| media | 真实媒体槽列表；三个独立换内容示例均为空，不依赖原片播放器 |

`frame`是配置帧率下的帧号。`points`、`counts`、`scaleKeys`、`yKeys`均为按帧升序的`[[帧,值],…]`。`keys`在锚点之间线性插值，前后保持端点值；不是作者原始关键帧。`rects`每项为`[x,y,w,h]`，使用1280×720逻辑画布坐标。

## 可直接调用的API

绘图函数签名为`fn(props, frame, theme)`，返回该时点的SVG标记，不依赖上一帧、系统时钟或播放方向。需要旧计数采样的组件额外接收curves。文字通过转义后输出。

独立绘图统一登记在`refinedRegistry`，可在自己的SVG中调用：

```js
import {refinedRegistry} from './src/refined-components.mjs';
const markup = refinedRegistry.independentMetrics(props, frame, theme);
```

环也可直接从`src/gap-ring.mjs`导入`pulsingRing`与`pulseRingState`；修复后`src/refined-components.mjs`也显式导出`pulsingRing`，整片命名空间调用与独立registry入口均可使用。数值状态函数不返回SVG，不能作为`component.type`交给独立绘图入口。

| 当前绘图组件 | 完整可传参数 | 行为 |
|---|---|---|
| independentMetrics | items、ats、counts、rects、duration、dark、labelY、numberY、numberSize、unitY、noteY | 每张卡自己的出现时刻、自己的数值曲线；items每项为value/label/unit/note。标签、数字、单位和说明分别定位 |
| growingGpu | title、value、note、footer、at、duration、dy、x、y、w、bar、barWidth、color | 卡片短入场，条线按bar另算长度，条线不跟卡片透明度共用同一进度 |
| growingBar | points、x、y、w、h、fill、track | 按points求0–1进度，绘固定底轨与可见长度；可用于计时条或视频红线 |
| stagedSteps | items、notes、ats、activeAts、duration、x、y、w、h、gap | ats决定每行何时出现，activeAts决定当前行何时切换，两者分开 |
| inputWorkbench | items、at、x、y、caption、note | 三框路径作为一组入场；当前内部框尺寸固定600×180，位置与内容可换 |
| flowPreview | at、dim、caption | 概念预览板建立，dim另控明暗退场；不冒充真实软件操作 |
| modelEmphasis | notes、labels、subnotes、placeholderAt、ats、duration、blocks | 弱态说明先出现，随后各组说明和黄色区域按ats建立。blocks每项为真实行范围[x,y,w,h] |
| windowShell | at、duration、x、y、w、h、yKeys、title、footer、dark | 只画窗口包装，内部真实媒体另设槽；yKeys只控制窗口局部入场位移 |
| audioOverview | at、reveal、x、y、w、h、bars、label、note | 面板入场、条线显示范围与局部波形分别计算；具体源波形相位仍是近似 |
| taskTerminal | objective、rows、rowFrames、at、x、y、w、h | 父板短入场，整行在rowFrames一次追加，不伪造逐字执行 |
| taskFeedback | items、ats、widths、x、y | 胶囊逐项建立；各自宽度和间隔共同决定后续胶囊位置 |
| continuousReceipt | lines、total、totalLabel、note、stamp、at、duration、stampAt、x、y、w、h | 账单只进入一次，印章另有出现时点；不在后段再次换一张几何 |
| phasedStorage | title、value、subtitle、family、titleAt、ringAt、familyAt、familyDuration | 标题、容量环、家庭轮廓分别建立 |
| videoBenefit | at、x、y、brand、title、note、progress | 源码概念视频卡。progress传给growingBar；其x/y是卡片内部坐标，默认条位于局部y=288、宽510 |
| pulsingRing | 见下节 | 固定缺口的环、灰底和文字整组轻呼吸，无旋转动画 |

| 纯状态与组合入口 | 输入和返回 |
|---|---|
| countState(frame, points, target) | 返回value和progress；用points最后的非零目标值归一化，再按target换目标，target省略则用原目标 |
| stagedState(frame, ats, duration) | 返回每项的入场alpha/y状态数组 |
| activeState(frame, ats) | 返回当前项索引；第一项尚未开始时为-1 |
| pulseRingState(props, frame) | 返回scale和growth；只计算状态，不绘图 |
| renderRefinedComponent(spec, frame, theme) | spec含type/props；调用已登记的绘图函数并返回SVG，不接受数值状态函数 |
| renderScene(config, seconds, curves) | 返回frame、scene、background、markup；component模式直接调用独立组件，否则按全片编排求值 |
| sceneAt(config, seconds) | 返回当前frame与scene，结束帧按半开区间选段 |
| mediaState(config, media, frame) | 返回visible、alpha、y；只控制登记媒体的可见范围、退场和局部位移 |

`keys`、`sampled`、`entry`、`clamp`、`mix`和`tx/lines/rect/group/panel`等基础函数仍从`src/components.mjs`导出。旧`registry`保留总览、价格卡、模型节点/线、桶、算力矩阵、公式、核对行、终端和结束卡等入口，其接口见[基础组件接口](基础组件接口.md)。旧gpuCard/metricPair/fourMetrics/modelList等函数只作兼容保留；本轮修好的独立增长、弱态时序、账单交棒应使用上表对应新函数，不能拿旧函数同名效果当已修版本。

## 呼吸环参数

| 参数 | 默认值或含义 |
|---|---|
| x / y / r / strokeWidth | 中心、半径、描边宽度；默认185/415/80/12 |
| track / color / ink / muted | 灰底、弧线、主文字、说明文字颜色；color默认theme.green |
| fraction | 弧线占整圆的比例；默认0.84。缺口取向固定，fraction不代表旋转速度 |
| at / duration | 弧长初次建立的起点与帧数；duration须大于0，与呼吸周期分开 |
| label / labelSize / labelY | 主文字及字号、基线；默认字号28、基线12 |
| subLabel / subLabelSize / subLabelY | 可选第二行，默认字号16、基线43 |
| caption / captionSize / captionY | 可选说明，默认字号12、基线65 |
| breathing.startFrame / endFrame | 周期呼吸启用的半开帧区间；按当前视频设置开始和结束帧 |
| breathing.periodFrames | 一个周期的帧数；示例采用55.3725帧，30fps约1.846秒 |
| breathing.amplitude | 相对缩放幅度；示例采用0.0299495，即约0.97005至1.02995 |
| scaleKeys | 不使用breathing时，可传明确的缩放锚点；两者同时提供时breathing优先 |

启用区间内的缩放为`1 + amplitude × sin(2π × (frame-startFrame)/periodFrames)`。灰底、弧线、文字共同缩放，中心与朝向固定。区间外返回scale=1；新视频应按镜头接续设置区间，不继承原参考片时码。
